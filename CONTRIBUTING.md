# Contributing to CodeVault-Community

Thank you for considering contributing. We welcome code, documentation, design, testing, bug reports, and thoughtful ideas.

## Getting started

1. Browse the [organization repositories](https://github.com/orgs/CodeVault-Community/repositories).
2. Read the README and contribution instructions in the project you want to help.
3. Check existing issues and pull requests before starting duplicate work.
4. For significant changes, open an issue first to discuss the proposed approach.

## Making contributions

- Keep pull requests focused and reasonably small.
- Use clear names and explain why a change is useful.
- Add or update tests when behavior changes.
- Update documentation when setup or user-facing behavior changes.
- Do not commit passwords, API keys, access tokens, personal data, or private information.
- Respect each project's existing architecture and license.

## Pull requests

Include a summary, motivation, testing details, and screenshots for meaningful interface changes. Link related issues when relevant. Be prepared to respond constructively to review feedback.

## Community expectations

Be respectful, patient, and welcoming. See our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping build an open and useful community.
