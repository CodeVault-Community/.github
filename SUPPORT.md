# Getting Support

For help with a project in CodeVault-Community:

1. Read that repository's README and documentation.
2. Search existing issues to see whether the question has already been answered.
3. For reproducible bugs, open an issue using the bug report template.
4. For questions or ideas, use the project's available discussion or issue channels.

When asking for help, include the project name, relevant version, operating system or environment, what you expected, and what happened. Remove passwords, tokens, personal data, and other secrets before sharing logs or screenshots.

Please be respectful of volunteer contributors and provide enough detail for others to understand the problem.
