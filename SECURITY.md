# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerability details, credentials, tokens, or private data in a public issue or pull request.

Use GitHub's **Report a vulnerability** feature on the affected repository when it is available. Otherwise, contact the repository owner or a maintainer privately through GitHub and include:

- The affected repository and component.
- A concise description of the issue and its potential impact.
- Reproduction steps or a proof of concept that does not expose real user data.
- Any suggested mitigation.

## Response

The maintainers will review the report, may ask for additional information, and will coordinate a fix and disclosure where appropriate. Please allow reasonable time for investigation before sharing details publicly.

## Supported versions

Support status is determined by each project's maintainers and release notes. If a project does not publish a support policy, ask its maintainers privately.
